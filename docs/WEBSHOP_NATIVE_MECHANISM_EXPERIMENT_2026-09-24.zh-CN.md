# WebShop Native：无策略提示的机制实验

承接用户对前 10 题至少 7 题严格成功的目标。约束为 WebShop 数据集通用，不使用 skill、强策略提示或针对题目/商品的特例。固定题集、seed=0、既有模型及 12+4=16 动作预算。用户进一步明确：当前只改进基线推理框架，尚未进入正式训练；本轮不更新任何模型参数。

## 撤回与边界

已撤回此前新增的购买收尾、规格选择、详情核对、查询改写及 Director 职责修订策略提示。Worker 指令表达式、两份原始 SkillFlow 页面模板和 Director 环境提示与第一轮修改前源码逐项核对相同。skill 仍为 off。

此前含提示的 5/10 只能作为历史结果保留，不能作为当前约束下的成绩。`r3` 为约束澄清前冻结的提示版，0 题完成、3 次连接拒绝导致中断，之后未重启，不计为有效评测。

当前保留纯事实反馈：未购买状态、实时候选、全图共享动作额度。删除了额外的自然语言完成要求。没有用固定动作顺序、强制购买或固定图结构替代被撤回的提示。

## 可复现的观察缺陷与修复

官方 `text` 模式用 `[SEP]` 抹平 HTML 控件；选择规格前后页面文字相同。后端已经记录的公开选择状态没有传给 Native Worker。

- `m1`：在当前观察和私有历史中补充当前 `selected_options`，仅限商品及详情页；不输出目录默认值、隐藏目标或奖励。
- 富文本候选：提供 opt-in `--observation-mode text_rich`，通过独立进程适配器选择官方现有富文本渲染器。保留按钮、已点击选项和访问标记，不改模拟器的动作、商品、目标及奖励函数。默认服务仍使用 `text`。
- 富文本搜索列表的公开 ASIN、标题与价格投影兼容原标记，避免观察格式变化破坏内部动作映射。

真实会话冒烟测试覆盖搜索、打开商品、选择选项、已选标记和会话清理，未购买或查询终局奖励。

## 证据与结果

目录：`state/experiments/webshop-native-target7-20260924/`。每轮保留完整源码及 SHA-256、独立评测目录。纯机制版与原指令一致的核对结果见 `constraint_audit.json`。

- `m1`：10/10 完成，严格成功 2/10。仍未达到 7/10。
- `m2`：初版富文本适配器缺少原 worker 的同目录导入路径，真实会话冒烟失败后停止；保留原始记录。
- `m2r`：服务重启时端口尚未释放，启动失败；评测因 3 次环境连接失败停止。保留原始记录，不当作准确率结果。
- `m2-valid`：修复并通过真实会话检查后的富文本完整对照，10/10 完成、1/10 严格成功、7/10 购买，平均分 50.00。未证明收益，富文本保持默认关闭。
- `m3`：选定输出物化机制，10/10 完成、2/10 严格成功、9/10 购买，平均分 58.83。购买完成率提高，但严格成功率没有提高，不能当成目标达成。三轮有效评测均为 0 次参数更新，无记录到的后端失败。

## 有界输出物化（m3）

新增默认关闭的 `canvas.native_webshop_output_materialization`。FINISH 时，选定节点已有报告但没有购买候选、图处于 clean 状态且仍有修订动作额度，则在同一会话执行该节点一次。上下文只增加选定输出阶段和输出类型两个事实字段。动作仍由 Worker 决定，不补充查询、购买、规格或搜索策略。所有动作计入原有共享 revision 及 total 额度，最多一次补执行，不挪用剩余 initial 额度。已有候选直接提交，不重执行。

回归覆盖会话续接、选中节点边界、重复 FINISH、无额度、已有候选、失败动作计费和状态隔离。m3 冻结后只补充了执行失效原因的事件审计标记，不改变该轮行为；后续源码快照包含该标记。

## 私有对话历史（m4）

新增默认关闭的 `webshop.native_conversation_history`。同一 Agent 的实际观察作为 user 回合，实际动作作为 assistant 回合，后续执行恢复这些回合。每个观察只在请求里出现一次，当前系统指令仍表达当前图分配职责。原有模板、Worker 指令和 Director 环境提示保持不变；不读取或传播模型私有推理文本，不共享其他 Agent 的会话，不增加动作或训练参数。

仅动作回合进入私有事务日志；报告继续只接收原有观察、动作和错误证据，逐步请求模板不进入报告。测试覆盖直接/路由执行、跨修订恢复、失败反馈和不同 Agent 隔离。与 m3 相比仅增加对话历史模式，原有选定输出物化开关维持开启。完整结果另存 m4：10/10 完成、1/10 严格成功、6/10 购买，平均分 37.17，没有改善，保持默认关闭。

前 10 题是开发集。即使达到 7/10，也需要独立题目验证才能讨论数据集通用收益；不得把挑选轮次或逐题拼接成功数当作同一轮结果。


## 公平对照约束与撤回 m5

用户明确要求公平对比，不能把 Worker 的 `reasoning_effort` 从 low 提高到 high。已停止 m5 high 评测并将其标记为不合格对照；保留部分原始记录，但不纳入 comparison.json，也不引用其分数作为框架收益。后续固定 low，模型与权重、原始指令、题集、seed、动作及 token 上限一致，只改变待验证的机制。不得把推理强度提升或计算额度增加包装成框架改进。

当前有效实验最高为 m1 / m3 的 2/10，尚未达到目标 7/10。当前源码相关回归测试 214 项通过，Ruff 与 diff 检查通过。m4 冻结后额外补齐了上下文模式的缓存身份，避免切换模式时复用旧执行结果；该补丁没有参与已完成的 m4 或被撤回的 m5。
